# Create Feature Branch and Submit Pull Request for Code Review

## Task Brief
Extend your portfolio repo with a feature branch, make code changes, and submit a pull request for peer review.

## Scenario
Your team lead asks you to add a features overview document via a feature branch and PR to practice collaborative workflows.

## Deliverables
- Feature branch with descriptive name
- Pull request with clear description
- Code changes ready for review

## Success Criteria
- PR title and description are clear
- Branch is up-to-date with main
- PR is open and awaiting review
