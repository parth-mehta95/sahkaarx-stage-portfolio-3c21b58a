# Resolve Single Merge Conflict in Portfolio

## Task Brief
Simulate and resolve one merge conflict in your portfolio repo to practice conflict resolution techniques.

## Scenario
Your team merged a feature branch that conflicts with main. Resolve the conflict manually and document your approach.

## Deliverables
- Resolved conflict in portfolio repo
- Commit with clear conflict resolution message
- Documentation of resolution steps

## Success Criteria
- Conflict markers removed and code merged correctly
- Commit history shows clean resolution
- README updated with conflict resolution notes
