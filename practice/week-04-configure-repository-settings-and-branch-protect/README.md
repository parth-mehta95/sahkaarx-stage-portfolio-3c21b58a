# Configure Repository Settings and Branch Protection

## Task Brief
Apply repository management best practices by setting up branch protection rules and configuring repository settings in your portfolio repo.

## Scenario
Your team requires branch protection rules to enforce code review before merging. Configure your portfolio repo with these settings.

## Deliverables
- Branch protection rules configured
- Repository settings documented

## Success Criteria
- Main branch requires pull request review
- Settings prevent direct pushes to main
