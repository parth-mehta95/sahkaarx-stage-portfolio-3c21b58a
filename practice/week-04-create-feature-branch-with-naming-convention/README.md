# Create Feature Branch with Naming Convention

## Task Brief
Extend portfolio repo with a feature branch using professional naming conventions and implement branching workflow.

## Scenario
Your team requires feature branches follow naming conventions. Create a branch for a new Python module and commit code changes.

## Deliverables
- Feature branch with descriptive name
- Commits following conventions
- Code ready for merge

## Success Criteria
- Branch name follows team convention
- Commits are atomic and well-documented
- Code changes are visible in git log
