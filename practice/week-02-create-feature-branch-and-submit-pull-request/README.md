# Create Feature Branch and Submit Pull Request

## Task Brief
Extend your portfolio repo with a feature branch, make code changes, and submit a pull request for code review.

## Scenario
Your team asks you to add a new feature to the portfolio project. Create a feature branch, implement changes, and open a PR.

## Deliverables
- Feature branch with commits
- Pull request with description

## Success Criteria
- PR references the main branch
- Commit messages are clear
