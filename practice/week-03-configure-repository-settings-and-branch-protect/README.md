# Configure Repository Settings and Branch Protection

## Task Brief
Apply repository management best practices by setting up branch protection rules and configuring repository settings in your portfolio repo.

## Scenario
Your team requires branch protection on main to prevent accidental pushes. Configure GitHub repository settings and branch protection rules.

## Deliverables
- Branch protection rules on main branch
- Repository settings documentation
- Configuration screenshot or summary

## Success Criteria
- Branch protection prevents direct pushes to main
- Require pull request reviews before merge
- Enforce status checks and dismiss stale reviews
